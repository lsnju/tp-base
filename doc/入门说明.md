# tp-base 入门说明

## 1. 项目定位

`tp-base` 是一个基于 Spring Boot 3 的 **基础能力框架仓库**，不是独立业务应用。  
目标是为业务系统提供统一的：

- Web 请求链路基础能力（Filter、AOP、异常处理、监控接口）
- 通用模型与响应规范（`BaseMo`、`BaseResp`）
- 通用工具能力（JSON、HTTP、加密、Money、日期等）
- 日志与配置模板（Logback/Log4j2、`application*.properties`）
- 版本治理（BOM）

核心 Maven 坐标：

- `com.lsnju.tp3:tp-base-parent`
- 代码库地址：`https://github.com/lsnju/tp-base`

---

## 2. 技术栈与环境要求

- Java: `17`
- Spring Boot 依赖基线：`3.5.15`（父 POM）
- 构建工具：Maven（建议 3.6+）
- 编码：UTF-8

常用本地命令：

```bash
mvn clean install
mvn test
mvn clean install -DskipTests
mvn clean install -pl tp-base -am
```

## 3. 仓库结构（多模块）

根 `pom.xml` 聚合了 18 个模块：

1. `tp-base-dep`：代码模块公共父 POM（Lombok、slf4j）
2. `tp-utils`：工具库
3. `tp-domain-multi`
4. `tp-domain-default`
5. `tp-domain-short`
6. `tp-domain-json`
7. `tp-domain-gson`
8. `tp-domain-jackson`
9. `tp-domain-jackson-mask`
10. `tp-rs-default`
11. `tp-rs-simple`
12. `tp-model`
13. `tp-base-log`
14. `tp-base-log4j2`
15. `tp-base-config`
16. `tp-base-dependencies`
17. `tp-base`
18. `tp-bom`

可以按职责分成四层：

- **核心能力层**：`tp-base`
- **模型/响应层**：`tp-model`、`tp-domain-*`、`tp-rs-*`
- **基础设施层**：`tp-utils`、`tp-base-config`、`tp-base-log`、`tp-base-log4j2`
- **版本管理层**：`tp-base-dependencies`、`tp-bom`

## 4. 关键模块说明

### 4.1 `tp-base`（框架核心）

`tp-base` 提供最核心的 Spring 能力装配，关键包：

- `com.lsnju.tpbase.annotation`：`@EnableTpBase` 等开关注解
- `com.lsnju.tpbase.autoconfigure`：自动配置与 Bean 装配
- `com.lsnju.tpbase.web.filter`：请求链路过滤器
- `com.lsnju.tpbase.log`：AOP 摘要日志
- `com.lsnju.tpbase.config.prop`：配置项绑定
- `com.lsnju.tpbase.web.controller`：监控/辅助接口

要点：本仓库采用 **注解 + `@Import` 显式启用**，不是标准 Starter 的自动发现模式。  
业务项目需要显式加注解（如 `@EnableTpBase`）。

### 4.2 `tp-utils`（工具库）

提供通用工具能力，常见包：

- `com.lsnju.base.gson`
- `com.lsnju.base.jackson`
- `com.lsnju.base.http5`
- `com.lsnju.base.money`
- `com.lsnju.base.secret`
- `com.lsnju.base.util`

### 4.3 `tp-model`（模型聚合入口）

集中提供基础模型类（如分页、结果对象）并聚合默认选型：

- 默认关联 `tp-domain-gson`
- 默认关联 `tp-rs-simple`

### 4.4 `tp-domain-*`（`BaseMo` 策略模块，互斥）

这组模块都定义同一个类：`com.lsnju.base.model.BaseMo`，差异在 `toString()`：

- `tp-domain-default` / `short` / `json` / `multi`
- `tp-domain-gson`
- `tp-domain-jackson`
- `tp-domain-jackson-mask`

**同一应用只能保留一个实现**，避免类冲突。

### 4.5 `tp-rs-*`（统一响应模块，互斥）

`tp-rs-default` 与 `tp-rs-simple` 定义了同名响应类（如 `BaseResp`、`RespEntityUtils`），同样应二选一。  
`tp-model` 默认选择 `tp-rs-simple`。

### 4.6 `tp-bom` 与 `tp-base-dependencies`（版本治理）

- `tp-base-dependencies`：仓库内部版本管理 BOM
- `tp-bom`：给业务项目导入使用的 BOM（推荐接入入口）

## 5. 业务项目如何接入

### 第一步：导入 BOM

```xml

<dependencyManagement>
    <dependencies>
        <dependency>
            <groupId>com.lsnju.tp3</groupId>
            <artifactId>tp-bom</artifactId>
            <version>${latest}</version>
            <type>pom</type>
            <scope>import</scope>
        </dependency>
    </dependencies>
</dependencyManagement>
```

### 第二步：引入核心依赖

```xml

<dependencies>
    <dependency>
        <groupId>com.lsnju.tp3</groupId>
        <artifactId>tp-base</artifactId>
    </dependency>
</dependencies>
```

### 第三步：在启动类显式开启能力

```java

@SpringBootApplication
@EnableTpBase
public class DemoApplication {
    public static void main(String[] args) {
        SpringApplication.run(DemoApplication.class, args);
    }
}
```

根据需要增加：

- `@EnableTpRestApiLog`：REST 接口入参/出参日志 AOP
- `@EnableTpMoConfig`：监控相关能力

### 第四步：覆盖配置项

参考 `tp-base-config/src/main/resources/application.properties`，重点关注：

- `tp.web.filter.*`
- `tp.aop.*`
- `tp.task.*`
- `tp.quartz.enable`
- `rest.api.profiler.timeout`

## 6. 开发与测试建议

- 先执行全量构建：`mvn clean install`
- 修改单模块时优先使用：`-pl <module> -am`
- 优先把核心回归测试放在 `src/test/java`
- 仓库中存在 `src/fun-test/java` 目录，默认 Maven 生命周期不会自动执行

---

## 7. 常见问题与踩坑

1. **能力不生效**：通常是少了 `@EnableTpBase` / `@EnableTpRestApiLog`
2. **类冲突**：`tp-domain-*` 或 `tp-rs-*` 同时引入多个实现
3. **运行时报类缺失**：部分依赖使用 `provided`，需要宿主项目补齐
4. **监控接口不存在**：未开启对应注解能力
5. **任务未执行**：`tp.quartz.enable` 默认可能为关闭状态

---

## 8. 新人 30 分钟上手路径

1. 阅读本文件 + `README.md`
2. 阅读根 `pom.xml` 的 `<modules>` 和 `tp-base/pom.xml`
3. 在业务项目按 BOM + `tp-base` 方式完成最小接入
4. 在启动类加 `@EnableTpBase`，启动验证
5. 根据项目要求选择唯一的 `tp-domain-*` 与 `tp-rs-*` 实现
6. 根据 `tp-base-config` 模板补齐本项目配置
